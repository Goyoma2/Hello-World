# AI論文・活用事例ダイジェスト

AIのプロフェッショナルを目指すための、定期配信ダイジェストです。
毎週、次の3つのレイヤーから情報を拾って `digests/YYYY-MM-DD.md` に追加します。

1. **古典・必読論文** — 現在のAIの土台になったエポックメイキングな論文（毎号1〜2本、順番に）
2. **最新の注目論文** — その週に話題になった研究
3. **活用事例** — 企業・研究現場での実際の使われ方

各項目は「概要」「何が革新的か（背景）」「リンク」で構成します。
